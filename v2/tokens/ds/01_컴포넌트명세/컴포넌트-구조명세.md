# 컴포넌트 구조명세

> 2026-11-12 피그마 BSS_DS_library_Component_v2.0 추출(토큰 근거 세트), 토큰 v2.0.3. Variant 값은 피그마 값 그대로이고, size 괄호는 높이(px)다(Modal은 너비, Scrollbar는 두께, Button type=icon plain은 20·16·14). 통합 세트(Button·Badge)는 컴포넌트마다 자기 type 변형만 적는다. (선택)은 Boolean 속성으로 켜고 끄는 요소다.

| Variant – variants | primary / secondary / base / accent / danger |

| Variant – state | default / hover / pressed / disabled |
| Boolean | showLeadingIcon(false) · showTrailingIcon(false) · showFocus(false) · showUnderline(false) |
| Text Property | label ("Button") |
