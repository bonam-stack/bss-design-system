## 참고

- **source**: 피그마 Text Field·Text Area, Search Field, Select·Dropdown, Date Field 페이지 적용값. 예시_Button(Search Field 페이지)은 예시라 제외. DatePicker·Calendar는 calendar 문서에서 다룬다
- **stateMap**: 피그마 entered·selected(값 있음)는 default, typing은 focus, readOnly는 readonly 상태로 본다. TextField·PasswordField·TextArea는 state(default·hover·focus·entered·readOnly·disabled) × invalid(false·true) × importance(none·attention·required)이고 invalid=true를 error 상태로 본다. entered는 추가한 값 입력 완료 모양(포커스 없음, 값 있음)으로 코드 상태는 default다(default·hover·focus에서 오류 테두리·링, readOnly·disabled는 그 상태 값). Select도 같은 축(state default·hover·open·selected·readOnly·disabled × invalid × importance)이고 open을 focus, selected(값 선택 완료)를 default로 본다. SearchField는 같은 축이고 LookupField는 state default·hover·selected·readOnly·disabled(focus 없음) × invalid × importance이고 selected(조회해 고른 값 있음)를 default로 본다. 값을 직접 입력하는 필드는 entered, 목록·조회에서 고르는 필드(Select·LookupField)는 selected다. DateField도 같은 축(state default·hover·focus·entered·readOnly·disabled × invalid × importance)이다. Stepper도 같은 축(state default·hover·focus·readOnly·disabled × invalid × importance, attention·required는 importance)이다
- **expandedState**: 셀렉트 listState=expanded(펼침)는 선언 상태가 아니라 펼침 표시용 토큰을 만들지 않았다. 펼침 상태에서 값이 있으면 꺾쇠가 gray 900이다(값이 없으면 button-iconOnly-plain-color-fg-default, gray 600)
- **cursor**: 입력 커서 색은 값 글자색과 같아(gray 900) 토큰을 만들지 않았다. CSS caret-color 기본값(currentColor)으로 같다
- **helper**: 필드 아래 도움말은 HelperText 인스턴스를 그대로 쓴다(caption/12/400). 도움말 치수·글자는 helperText 문서에서 다룬다
- **textArea**: textArea 입력 글자 스타일은 body/14/400이다(다른 필드는 사이즈별 label/16/400·15/400·14/400)
- **lookupField**: 검색 버튼은 button-iconOnly(outlined base) 인스턴스라 button 그룹 토큰을 쓴다. readonly에서 버튼이 disabled 모양이 된다
- **dateFieldWidth**: dateField 너비는 모드·사이즈별 고정이다(안내 글자 YYYY.MM.DD와 값 숫자의 글자 폭이 달라 내용에 맞추면 입력 전후로 크기가 바뀌므로): date 136·132·120, dateTime 212·200·188, dateRange 248·236·220, dateTimeRange 396·376·352(large·medium·small, px). 입력 상자 안은 시작 여백(paddingStart) + 입력 글자(남는 폭을 채움, 왼쪽 정렬) + 간격(dateField-space-gap) + 달력 버튼 + 끝 여백(paddingEnd)이고, 기간은 시작·끝 입력 칸이 같은 너비를 나눠 쓴다. 너비 토큰은 두지 않고 구현값으로 쓴다(TextField처럼 화면에서 너비를 정해도 된다)
- **selectList**: 옵션 목록 그림자는 select-list-shadow(→ shadow-medium). 목록 높이(284·256·228)는 내용에 따른 값이라 만들지 않았다
- **iconColor**: 필드 안 아이콘은 컴포넌트마다 원본 토큰을 쓴다: 지우기·달력·검색 아이콘 버튼은 button-iconOnly plain, 셀렉트 꺾쇠는 button-iconOnly-plain-color-fg-default·-disabled, 비밀번호 보기 토글은 visibilityToggle 토큰
- **padding**: 입력 상자 좌우 여백이 다른 필드는 paddingStart·paddingEnd를, 좌우가 같은 lookupField는 paddingX를 쓴다
- **focusRingRadius**: 포커스 링 모서리: [컴포넌트]-[사이즈]-focusRing-radius는 요소 모서리 + 2(원형은 원형, 모서리 0은 focusRing-radius 4)다. Semantic을 만들지 않고 Primitive radius-[값]을 직접 참조한다. 피그마 변수가 계산식을 지원하지 않아 CSS calc 대신 토큰으로 둔다. 요소 모서리가 바뀌면 링 모서리 토큰도 함께 바꾼다
- **selectOption**: 선택된 옵션의 hover·pressed 바탕은 브랜드(tBlue 50·80)이며 select-selected-option-color-bg-*를 쓴다. 선택 안 된 옵션은 select-option-color-bg-*를 쓴다. 옵션 포커스 링 모서리는 select-option-focusRing-radius(6 = 옵션 모서리 4 + 2)를 쓴다
- **stepper**: stepper는 사이즈 large(40)·medium(36)·small(28)이고 상태는 다른 필드와 같다(attention·required 포함). 색은 field 공통 토큰을 그대로 쓰고 치수는 높이(사이즈별)·모서리·테두리 두께·도움말 간격·포커스 링 모서리, −/+ 버튼 칸(stepButton)과 숫자 칸(input)의 좌우 여백(사이즈별)을 둔다. 칸 너비는 내용에 좌우 여백을 더해 정해져 너비 토큰은 두지 않는다. −/+ 버튼은 button-iconOnly(plain base) 인스턴스라 button 그룹 토큰을 쓰고(아이콘 large·medium 16, small 14), readonly·disabled에서 버튼이 disabled 모양이 된다. 포커스 링은 입력 상자 바깥에 있어 사이즈별 stepper-[사이즈]-focusRing-radius(모두 8)를 쓴다. 입력 중 커서는 숫자 칸 레이아웃 밖(절대 위치)에 두어 칸 너비를 바꾸지 않는다. 단계 표시 steps와 다른 컴포넌트다
- **borderStronger**: 필드(TextField·Select·DateField·Stepper 등)의 기본·hover 테두리는 color-border-neutral-stronger(gray 400)를 쓰며 field 배리어블에 연결한다. base 버튼 테두리도 같은 Semantic을 쓴다
- **searchFieldIcon**: searchField 검색 아이콘은 앞쪽 IconSlot이다. 아이콘 색은 상태별 글자 색과 같아 field-color-fg-*·field-placeholder-color-fg-default를 함께 쓰고, 크기는 searchField-[사이즈]-icon-size를 쓴다. 좌우 여백이 같아 paddingX 하나를 쓴다
- **stepperCursor**: typing 입력 커서는 부품 _Item/Stepper/Cursor(9791:497, 1×14)다. 색은 field-color-fg-focus(값 글자색과 같음)에 연결돼 있어 커서 전용 토큰은 두지 않는다. 커서는 숫자 칸 레이아웃 밖(절대 위치, 글자 바로 뒤)에 두어 칸 너비를 바꾸지 않는다
- **stepperFocusRingSize**: 사이즈가 있는 컴포넌트의 포커스 링 모서리는 공식대로 사이즈별로 둔다(값이 같아도 합치지 않음). stepper는 stepper-{large·medium·small}-focusRing-radius(모두 radius-8)를 쓴다
- **requiredReadonly**: required(필수) 변형의 읽기 전용(readOnly)은 일반 읽기 전용과 같은 색이다. field-required-color-bg·border-readonly는 상태 세트 규칙에 따라 두고 일반과 같은 Semantic을 참조한다(disabled와 같은 방식). attention(강조) 변형의 읽기 전용은 진한 노랑(field-attention-color-bg·border-readonly) 그대로다
