## 사이즈별 값

> 컴포넌트 사이즈 단어(xlarge·medium …)와 Semantic 단계 단어(`radius-medium`, `size-icon-small` …)는 서로 다른 척도다. 값은 이름으로 짐작하지 말고 이 표나 토큰 목록에서 확인한다. 칸마다 최종 값과 거친 Semantic(없으면 Primitive 직접 참조)을 적었다.

## 참고

- **source**: 피그마 Button 페이지 통합 세트 Button(7225:918) 적용값. type=square·round·icon·iconPlain·text가 button-action·button-inline·button-iconOnly(icon·iconPlain)·button-text다
- **icon**: button-action·button-inline·button-text의 아이콘은 IconSlot이 숨김 상태라 색을 확인하지 못했다. button-iconOnly(outlined)의 아이콘 색은 같은 유형의 글자 색과 모든 상태에서 같으므로 아이콘 토큰을 따로 만들지 않았다. button-text 아이콘(showLeadingIcon·showTrailingIcon)도 글자 색을 따른다
- **primaryBorder**: primary 버튼에는 테두리가 없어(적용값 없음) button-primary-color-border-*를 만들지 않았다
- **paddingY**: 모든 버튼의 위아래 여백은 0이고 높이로 크기를 맞추므로 paddingY 토큰을 만들지 않았다
- **boundTo**: evidence의 boundTo는 현재 피그마 연결 기록이며 값 판단에 쓰지 않았다. 치수는 연결 여부를 조회하지 않아 unknown
- **dangerPressed**: danger 버튼 pressed 바탕은 color-bg-danger-muted(red 80)를 쓴다
- **iconOnlyPlain**: button-iconOnly plain(바탕·테두리 없는 회색 아이콘)은 다이얼로그 닫기·뷰어 툴바·표 머리 정렬·칩 등 여러 컴포넌트가 함께 쓰는 공용 유형이다. 색은 button-iconOnly-plain-color-fg-*(gray 700/800/900/400), 크기는 button-iconOnly-[사이즈]-icon-size(20·16·14), 요소 모서리 0, 포커스 링 모서리 focusRing-radius(4)
- **textFocusRing**: button-text(모서리 0)의 포커스 링 모서리는 유틸리티 토큰 focusRing-radius(4px)를 쓴다
- **focusRingRadius**: 포커스 링 모서리: [컴포넌트]-[사이즈]-focusRing-radius는 요소 모서리 + 2(원형은 원형, 모서리 0은 focusRing-radius 4)다. Semantic을 만들지 않고 Primitive radius-[값]을 직접 참조한다. 피그마 변수가 계산식을 지원하지 않아 CSS calc 대신 토큰으로 둔다. 요소 모서리가 바뀌면 링 모서리 토큰도 함께 바꾼다
- **borderStronger**: Button 원본(base·outlined)의 기본·hover·pressed 테두리는 color-border-neutral-stronger(gray 400)를 쓰며 button/base 배리어블에 연결한다(필드 테두리와 같은 Semantic)
