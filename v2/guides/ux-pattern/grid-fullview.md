일반목록 상태바의 '전체보기'로 여는 딤 팝업입니다.
배경을 어둡게 덮고 표를 화면 가득 펼쳐, 화면 이동 없이 제자리에서 크게 봅니다.
컬럼이 많거나 데이터를 넓게 훑어야 할 때 기본 목록보다 넉넉한 폭으로 탐색합니다.

#### 개요 · 언제 쓰나요?

테이블 전체보기는 [일반목록](grid-board.html) 상태바 우측의 '전체보기'로 진입하는 딤 팝업입니다.
배경을 어둡게 덮고, 표를 화면 가득 넓게 펼쳐 화면 이동 없이 제자리에서 크게 봅니다.
컬럼이 많거나 데이터를 넓게 훑어야 할 때, 기본 목록보다 넉넉한 폭으로 탐색할 수 있는 것이 이 패턴의 목적입니다.

핵심 원칙테이블 전체보기는 목록을 더 크게 보는 보조 뷰이지 별도의 데이터가 아닙니다.
원본 목록과 같은 데이터를 그 자리에서 크게 볼 뿐입니다.

테이블 전체보기는 특정 패턴 전용 기능이 아니라, 특별한 예외가 없는 한 테이블 형태의 모든 컨텐트에 공통으로 적용되는 기능입니다.다만 다단 구성의 보조 테이블처럼 크게 볼 의미가 없는 경우에는 예외적으로 적용하지 않을 수 있습니다.
###### ✓ 이럴 때 사용합니다

- 컬럼·행이 많아 기본 목록 폭에서 답답하게 잘려 보일 때
- 데이터를 넓게 펼쳐 비교·탐색하거나 확대해 자세히 봐야 할 때
- 화면을 옮기지 않고 제자리에서 목록만 크게 보고 싶을 때

###### ✕ 다른 패턴을 사용합니다

- 한 건을 깊이 확인·편집할 때 → [행확장 편집](grid-expand.html) · [사이드 패널](option-panel.html) · 팝업
- 기본 폭으로 충분한 단순 목록 → 일반목록

#### 구성

테이블 전체보기의 컨텐트 레이아웃은 [일반목록](grid-board.html)과 동일합니다.
팝업 안에도 컨텐트 유틸리티(검색·필터) · 액션 영역 · 테이블 · 상태바가 같은 구조로 들어가고, 여기에 딤 배경과 팝업 헤더(타이틀·확대/축소·닫기)가 더해집니다.

1. 딤 배경뒤 화면을 어둡게 덮어 팝업에 시선을 모읍니다. 배경을 클릭하면 팝업이 닫힙니다.
2. 팝업 헤더좌측에 타이틀, 우측에 확대/축소(−/+/초기화)와 닫기(X)를 둡니다.
3. 컨텐트 유틸리티 (검색·필터)팝업 자체의 검색·필터·초기화·상세조회입니다.
4. 액션 영역 (삭제·등록 등)목록에 대한 실행 버튼을 우측 상단에 둡니다. 일반목록 액션 영역과 동일하게 등록·삭제 같은 조작을 같은 자리에 배치합니다.
5. 테이블일반목록과 같은 표입니다. 헤더(타이틀)는 세로 스크롤 중에도 상단에 고정(스티키)하고, 컬럼이 넓으면 가로로 스크롤합니다.
6. 상태바총 건수(좌) · 페이지네이션(중앙) · 목록 개수 선택(우)으로 마감합니다.

#### 핵심 동작 · 상태

기본 동작(정렬 · 필터 · 상태 처리)은 [테이블 모듈 공통 정의](grid-basic-behavior.html)와 [일반목록](grid-board.html)을 따르며, 테이블 전체보기는 다음을 더합니다.

- **진입·닫기**: 상태바 '전체보기'로 열고, X · Esc · 배경(딤) 클릭으로 닫습니다.
- **독립 상태**: 팝업의 검색·필터·페이지네이션은 원본 목록과 별개로 팝업 안에서만 적용됩니다.
- **확대·축소(엑셀식)**: 컬럼이 많은 넓은 표에서 Ctrl + 마우스 휠(또는 줌 −/+/초기화)로 배율을 조절합니다. 축소하면 셀이 작아지며 더 많은 열이 한눈에 들어오고, 넘치는 열은 가로 스크롤로 봅니다. 커서 위치를 기준으로 배율이 조정되며, 팝업 안 어디에서 굴려도 표에만 적용됩니다.
- **스티키 헤더**: 표 헤더는 세로 스크롤 중에도 상단에 고정되어 지금 보는 값이 어느 열인지 놓치지 않게 합니다.
- **상태**: Loading · Empty · Error 처리는 테이블 모듈 공통 정의를 따릅니다.

#### 실제 예시

테이블 전체보기 딤 팝업이 열린 기본 상태입니다.
팝업 안에서 검색·필터·페이지네이션, Ctrl + 휠 확대/축소, 헤더 고정을 직접 확인할 수 있습니다.

테이블 전체보기 · 딤 팝업 화면새 탭에서 크게 보기※ 예시 이미지 — 레이아웃/디자인은 확정 아님. 패턴 구조만 참고.
#### Do / Don't

###### Do · 이렇게 합니다

- 테이블 전체보기는 목록을 크게 보는 보조 뷰로 쓰고, 닫으면 원래 목록으로 그대로 돌아오게 합니다.
- 팝업 안 검색·페이지네이션은 원본 목록과 독립으로 동작시킵니다.
- 표 헤더를 스티키로 고정하고, 넓은 표는 가로 스크롤로 처리합니다.
- 닫기를 X · Esc · 배경 클릭 세 가지로 모두 제공합니다.

###### Don't · 이건 피합니다

- 테이블 전체보기 팝업에서 원본 목록과 다른 데이터·구조를 보여 주지 않습니다.
- 딤 배경 없이 띄워 뒤 화면과 구분이 안 되게 하지 않습니다.
- 한 건 상세 편집 같은 무거운 업무를 테이블 전체보기 팝업에 억지로 넣지 않습니다.
- 닫기 수단을 X 하나로만 제한하지 않습니다.
