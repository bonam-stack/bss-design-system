항목이 상위 그룹과 하위 항목으로 계층을 이루는 데이터를, 접고 펼치는 트리 테이블로 조회하는 목록 패턴입니다.
깊이 있는 구조를 한눈에 훑고 원하는 묶음으로 좁혀 보는 것이 핵심입니다.

#### 개요 · 언제 쓰나요?

[일반목록](grid-board.html)이 평면 목록이라면, 트리형 목록은 항목이 상위 그룹과 하위 항목으로 계층을 이루는 목록입니다.
상위 그룹을 접고 펼치며 깊이를 다루고, 검색으로 원하는 묶음을 빠르게 찾습니다.
그룹 행에는 하위 항목의 집계(합계 · 개수)를 함께 보여, 펼치지 않고도 묶음 단위의 규모를 파악할 수 있습니다.
구체적인 데이터 구조 · 필드명 · 색상 값은 구현 · 디자인 가이드에서 정하며, 이 문서는 구조 · 관계 · 동작을 다룹니다.

###### ✓ 이럴 때 사용합니다

- 항목이 상위·하위로 묶여 깊이(계층)가 있는 목록 (분류 체계 · 계층 코드 등)
- 그룹별 합계·개수를 함께 보며 묶음 단위로 규모를 파악해야 하는 목록

###### ✕ 다른 패턴을 사용합니다

- 계층 개념이 없는 단순 목록 → 일반목록
- 열이 많아 좌우로 넓게 보는 표 → [빅 테이블](grid-biggrid.html) (좌우 스크롤)

#### 장점 · 한계

계층으로 묶으면 평면 목록에서는 흩어지는 맥락과 갈래가 구조 그대로 드러납니다.

- **맥락이 한눈에**: 어떤 묶음에 무엇이 딸리는지 상하 관계로 보여, 구조를 따라 읽기 쉽습니다.
- **갈래가 엉키지 않음**: 한 뿌리 아래 여러 줄기로 갈라져도 각 하위 트리에서 독립적으로 다뤄져, 서로 다른 갈래가 섞이지 않습니다.
- **묶음 단위 집계**: 그룹 행에 하위 합계·개수를 얹어, 펼치지 않고도 묶음의 규모를 가늠할 수 있습니다.
- **한계**: 깊이가 지나치게 늘면 오히려 전체를 파악하기 어렵고, 항목 간 단순 비교·랭킹에는 평면 목록이 낫습니다. (→ [일반목록](grid-board.html) · [합계통계형 목록](grid-sum.html))

#### 구성요소

트리형 목록은 [컨텐트 모듈 개요](layout-content.html)의 컨텐트 영역 안에 놓이는 목록으로, 위→아래로 다음 네 부분으로 이루어집니다.

1. 컨텐트 유틸리티 (검색)트리를 좁히는 상단 검색 줄입니다.이름 · 코드 같은 텍스트와 기간 조건으로 검색합니다.조건을 입력한 뒤 상세조회로 적용하는 submit 방식입니다.
2. 액션 영역좌우로 필터와 내보내기를 나눠 둡니다.좌측에 상태 패싯 칩을 두어, 누르면 해당 상태만 즉시 추립니다.우측에 엑셀 다운로드를 둡니다.
3. 계층 트리 테이블상위 그룹으로 묶고 하위(잎) 항목을 나열하는 본문입니다.그룹 행을 접고 펼쳐 깊이를 조절합니다.그룹 행에는 하위 항목의 집계(수치 열 합계 · 하위 개수)를 함께 표시합니다.상태는 칩으로 구분하고, 잎 행의 '수정'은 사이드 패널(편집)로 엽니다.
4. 상태바깊이 제어와 크게 보기를 두는 하단 줄입니다.좌측에 펼침 레벨 선택과 총 건수를 둡니다.결과가 많으면 상위 그룹 단위로 스크롤하며 이어서 불러옵니다.우측에 표 전체를 팝업으로 크게 보는 전체보기를 둡니다.

#### 핵심 동작 · 상태

- **트리 탐색 · 검색**: 텍스트 · 기간으로 걸러 찾고, 펼침 레벨로 깊이를 조절합니다. 그룹 행을 접고 펼쳐 필요한 묶음만 봅니다.
- **상태 필터**: 상태 패싯 칩으로 원하는 상태만 즉시 추립니다.
- **그룹 집계**: 그룹 행에 하위 항목의 수치 합계와 개수를 얹어, 펼치지 않고도 규모를 봅니다.
- **행 수정**: 잎 행의 '수정'으로 사이드 패널을 열어 편집합니다. (그룹 행은 클릭 대상이 아닙니다)
- **무한 스크롤**: 상위 그룹 단위로 스크롤하며 이어서 불러옵니다. (계층·그룹 트리에는 페이지네이션을 두지 않습니다)
- **내보내기**: 엑셀 다운로드로 현재 목록을 내보냅니다.
- **전체보기**: 상태바의 전체보기로 표 전체를 팝업에서 크게 봅니다.

#### 실제 예시

상위 그룹으로 묶인 계층 목록입니다.
그룹 접기 · 펼치기, 상태 필터, 잎 행 '수정'의 사이드 패널, 전체보기를 직접 눌러 확인할 수 있습니다.

트리형 목록 · BSS 표준 화면새 탭에서 크게 보기※ 예시 이미지 — 레이아웃/디자인은 확정 아님. 패턴 구조만 참고.
#### Do / Don't

###### Do · 이렇게 합니다

- 계층은 접기 · 펼치기로 다루고, 검색 · 펼침 레벨로 원하는 묶음을 빠르게 찾게 합니다.
- 그룹 행에 하위 합계 · 개수를 얹어 펼치지 않고도 규모를 파악하게 합니다.
- 상태 필터로 원하는 상태만 즉시 추리게 합니다.
- 결과가 많으면 무한 스크롤로 이어서 불러옵니다.

###### Don't · 이건 피합니다

- 트리 깊이를 과도하게 늘려 한눈에 안 들어오게 하지 않습니다.
- 계층이 없는 단순 목록에까지 트리를 씌우지 않습니다. (→ 일반목록)
- 계층·그룹 트리에 페이지네이션을 쓰지 않습니다. (펼침·접힘과 충돌)
- 그룹 행을 잎 행처럼 클릭 편집 대상으로 만들지 않습니다.
