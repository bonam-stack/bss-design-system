그룹 없는 평면 목록 하단(또는 상단)에 합계·평균·카운트 집계 행을 고정해, 개별 항목을 그대로 보면서 전체 집계를 함께 읽는 리포트형 표 패턴입니다.
재무·통계·정산처럼 항목을 나열하고 마지막에 합계를 맞추는 화면에 씁니다.

#### 개요 · 언제 쓰나요?

합계통계형 목록은 [일반목록](grid-board.html)의 확장형입니다.
그룹 계층 없이 개별 항목을 평면으로 나열하고, 목록 하단(또는 상단)에 합계·평균 같은 집계 행을 고정해 스크롤과 무관하게 전체 값을 항상 보여 줍니다.
개별 항목이 중심이고, 집계 행이 그 목록을 마감하는 구조입니다.

핵심 원칙이 패턴의 중심은 개별 항목(행)입니다.
항목을 그대로 나열·정렬·비교하면서, 하단에 고정된 합계·평균으로 전체 규모를 언제든 확인합니다.
집계 행은 스크롤 영역 밖의 고정 밴드(Sticky Footer)에 두어, 데이터가 길어도 화면에서 사라지지 않게 합니다.

###### ✓ 이럴 때 사용합니다

- 재무·통계·정산 리포트 (예. 일/월별 매출, 상품별 수익, 정산 명세, 청구 집계)
- 개별 항목을 나열·정렬해 순위·비중을 보고, 마지막에 전체 합·평균을 맞춰야 하는 화면
- 검색·필터로 부분집합을 고른 뒤 그 부분합을 즉시 확인해야 하는 화면

###### ✕ 다른 패턴을 사용합니다

- 카테고리별 중간 집계(소계)를 계층으로 봐야 하는 화면 → [피벗 목록](grid-group.html)
- 집계 없이 개별 행만 확인하고 찾는 목록 → 일반목록
- 결과가 방대해 페이지 단위로 끊어야 하는 목록 → 일반목록(페이지네이션)

#### 피벗 목록과의 차이

같은 집계 표지만 [피벗 목록](grid-group.html)과는 바라보는 방향이 반대입니다.
이 차이가 두 패턴의 사용성을 가릅니다.

핵심 원칙피벗 목록이 거시 → 미시(카테고리 소계를 먼저 보고 그룹을 바꿔가며 다면으로 파고드는 하향식)라면, 합계통계형 목록은 미시 중심(개별 항목을 그대로 나열·리포트하고 전체 합으로 마감하는 상향식)입니다.

피벗 목록그룹(축)으로 묶어 소계·총계를 계층으로 봅니다.
축을 바꿔가며 같은 데이터를 여러 각도로 분석하는 다면 분석에 강합니다.
개별 항목은 그룹 안에 접혀 들어갑니다.

합계통계형 목록개별 항목이 중심입니다.
평면으로 나열해 정렬·비교하고, 하단 집계로 전체를 맞춥니다.
항목 단위 리포트와 랭킹, 부분집합 집계에 강합니다.

- **강점**: 개별 항목을 손대지 않은 값 그대로 보여 줍니다. 정렬로 랭킹을 만들고, 검색·필터로 좁힌 부분집합의 합·평균을 즉시 확인할 수 있습니다. 집계 행이 항상 붙어 있어 지금 보는 목록의 합을 놓치지 않습니다.
- **한계**: 그룹 계층이 없어 카테고리별 중간 집계(소계)는 드러나지 않습니다. 그런 계층 비교가 필요하면 피벗 목록을 씁니다. 또 페이지네이션 없이 전량을 나열하므로, 항목이 지나치게 많으면 스크롤 부담이 커집니다.

#### 구성요소

합계통계형 목록은 [컨텐트 모듈 개요](layout-content.html)의 컨텐트 영역 안에 놓입니다.
[일반목록](grid-board.html)과 뼈대는 같으며, 목록 아래에 집계 상태바가 붙고 페이지네이션이 없는 점이 다릅니다.

1. 컨텐트 유틸리티 (검색·필터) — 선택·권장목록을 좁히는 컨텐트 유틸리티 줄입니다. 없어도 되지만(선택), 이 패턴은 오히려 검색·필터와 결합할 때 가장 유용합니다. (아래 검색 옵션·패싯 필터와의 궁합 참조)
2. 데이터 표 (평면 목록)그룹 없이 개별 항목을 나열하는 본문입니다. 정렬 가능한 고정 헤더를 두고, 결과가 많으면 이 영역 안에서 세로 스크롤합니다.
3. 집계 상태바 (합계·평균·카운트)스크롤 영역 밖에 고정된 밴드입니다. 평균·총계 같은 집계 행을 담고, 데이터 표와 같은 컬럼 폭으로 정렬됩니다. 세로 스크롤바는 데이터 행에만 걸리고 집계 행은 항상 보입니다.

#### 집계 행 · 계산 기준

핵심 원칙합계·평균·카운트 행은 상단 또는 하단에 고정(Sticky)해 스크롤과 무관하게 노출합니다.
목업은 하단 상태바 방식으로, 위에서부터 평균(라벤더)·총계(다크) 두 줄을 쌓아 총계로 마감합니다.

- **역할**: 합계·평균 같은 집계 결과를 한 줄로 보여 줍니다. 카운트(총 N개)는 총계 행 옆에 함께 표기합니다.
- **평균 행은 필요할 때만 둡니다**: 평균이 필요하지 않으면 평균 행을 생략하고 총계 행만 둡니다. 기획에 필요하면 평균 대신 다른 통계 수치를 둡니다. (예. 중앙값 · 최댓값 · 최솟값)
- **배치**: 표 맨 아래(또는 맨 위) 고정 줄에 둡니다. 스크롤 영역 밖의 밴드라 데이터가 길어져도 사라지지 않습니다.
- **컬럼별 계산 기준**: 같은 집계 행이라도 컬럼마다 계산 방식이 다릅니다. (예. 수량·금액은 단순 합, 증감률은 매출 가중평균, 구성비는 전체 대비 100%) 각 행 %를 단순히 더하면 총계와 안 맞는 경우가 있어, 헤더의 ⓘ 툴팁으로 계산 방식을 안내합니다.

#### 검색 옵션·패싯 필터와의 궁합

핵심 원칙컨텐트 유틸리티는 선택이지만, 합계통계형 목록은 검색·필터와 함께일 때 가장 유용합니다.
특히 목업의 패싯(facet) 칩 필터와 궁합이 좋습니다.

- **패싯 칩 = 즉시 부분합**: 카테고리 칩(전체·유형 A·B…)을 누르면 목록이 그 부분집합으로 즉시 필터되고, 집계 행이 부분합으로 다시 계산됩니다. 고른 만큼의 합·평균을 바로 읽는 동적 집계입니다.
- **부분합임을 명시**: 필터가 걸리면 총계는 전체가 아니라 부분합이므로, 총계 옆 라벨에 활성 필터·건수(예. `· 유형 A · 6개 항목`)를 붙여 지금 값이 부분합임을 분명히 합니다.
- **비중도 부분집합 기준**: 구성비(기여도)처럼 전체 대비 값을 쓰는 컬럼은, 필터 시 부분집합 내 100%로 재계산합니다.
- **다른 검색과도 결합**: 패싯뿐 아니라 상단 조회조건·상세검색과도 자연스럽게 이어집니다. 조건으로 좁힐수록 하단 집계가 그 결과의 요약이 됩니다.

#### 핵심 동작 · 상태

기본 동작(정렬 · 상태 처리)은 [테이블 모듈 공통 정의](grid-basic-behavior.html)와 [일반목록](grid-board.html)을 따르며, 합계통계형 목록은 다음을 추가로 갖춥니다.

- **정렬 = 랭킹**: 숫자·텍스트 열을 정렬해 항목 순위를 만듭니다. 집계 행 값은 행 순서와 무관하므로 정렬해도 변하지 않습니다.
- **필터 재집계**: 패싯 칩·검색으로 부분집합이 바뀌면 집계 행(합·평균·구성비)을 즉시 다시 계산합니다.
- **집계 밴드 고정**: 평균·총계 밴드는 스크롤 영역 밖에 있어 데이터가 길어도 항상 보입니다.
- **페이지네이션 대신 무한 스크롤**: 집계가 전량 기준이어야 하므로 페이지로 끊는 페이지네이션은 쓰지 않습니다. 대신 결과가 많으면 무한 스크롤로 목록을 이어 붙여 페이징합니다. 이때도 하단 집계 밴드는 전체(또는 필터된 부분집합) 기준으로 고정되어, 아직 다 로드되지 않았더라도 합·평균은 전량 기준으로 보여 줍니다.
- **상태**: Loading · Empty · Error 처리는 테이블 모듈 공통 정의를 따릅니다.

#### 실제 예시

예시 데이터입니다.
상품군 패싯 칩으로 부분집합을 고르면 하단 집계(평균·총계)가 부분합으로 재계산되는 것, 숫자 열 정렬(랭킹), 스크롤과 무관하게 고정되는 집계 밴드, 헤더 ⓘ의 계산 방식 안내를 직접 확인할 수 있습니다.

#### Do / Don't

###### Do · 이렇게 합니다

- 개별 항목을 그대로 나열·정렬하고, 하단에 합계 등 집계 행을 고정해 전체를 맞춥니다.
- 집계 행은 스크롤 영역 밖 고정 밴드에 두어 항상 보이게 합니다.
- 검색·패싯 필터와 결합해, 부분집합의 합·평균을 즉시 재계산합니다.
- 필터가 걸리면 총계 옆에 활성 필터·건수를 붙여 부분합임을 명시합니다.

###### Don't · 이건 피합니다

- 카테고리별 소계 계층이 필요한데 합계통계형 목록으로 풀지 않습니다. (→ 피벗 목록)
- 집계 행을 스크롤과 함께 밀려 사라지게 두지 않습니다.
- 컬럼별 계산 기준(가중평균·구성비)을 감춰 행 %의 합이 총계와 달라 혼란을 주지 않습니다.
- 필터로 좁힌 부분합을 전체 총계처럼 보이게 두지 않습니다.
