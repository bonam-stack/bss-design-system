주소를 받는 입력란에서 주소찾기 팝업을 열어 주소를 검색하고, 고른 주소를 입력란 하나에 표시하는 방식을 규정합니다.

#### 개요 · 언제 쓰나요?

청구 주소 · 설치 주소 · 배송지처럼 주소를 받는 화면에서 쓰는 공통 기능입니다.
주소는 직접 입력하지 않고 주소찾기 팝업에서 검색해 입력란에 표시합니다.
모든 채널에 같은 규칙을 적용합니다.

###### ✓ 이럴 때 사용합니다

- 주소를 새로 받거나 바꾸는 경우 (예. 청구 주소 변경 · 설치 주소 입력)

###### ✕ 다른 패턴을 사용합니다

- 주소를 보여 주기만 하는 경우 → 표시 규칙은 [마스킹 처리](resp-masking.html)

#### 구성요소

1. 주소 입력란주소를 보여 주는 읽기 전용 입력란과 ‘주소찾기’ 버튼입니다. 버튼을 눌러도, 입력란을 눌러도 주소찾기 팝업이 열립니다. 버튼에는 [팝업 아이콘](popup.html)을 둡니다.
2. 주소찾기 팝업주소를 검색하고 상세 주소까지 받는 [고정 팝업](popup.html)입니다. 어디서 열든 같은 팝업입니다.

기본 정책1. 주소는 주소찾기 팝업에서 검색해 입력란에 표시합니다.
2. 결과에서 도로명주소와 지번주소 중 고른 주소를 표시합니다.
3. 주소는 입력란 하나에 `(우편번호) 주소, 상세 주소` 형식으로 표시합니다.
4. 주소를 고칠 때는 ‘주소찾기’를 다시 진행합니다.

#### 핵심 동작 · 상태

##### 주소찾기 팝업

검색 → 결과에서 도로명주소 · 지번주소 선택 → 상세 주소 → ‘적용’ 순서로 팝업 하나에서 끝냅니다.
어디서 열든 같은 팝업이며, 고른 주소는 팝업을 연 자리의 입력란에 표시됩니다.

- **검색어**: 도로명 + 건물번호, 동/읍/면 + 지번, 건물명으로 찾습니다. 결과가 없으면 검색 팁을 보여 줍니다.
- **결과**: 결과마다 도로명주소와 지번주소를 함께 보여 주고, 둘 중 하나를 고릅니다.
- **표시하는 주소**: 고른 주소 그대로 표시합니다. 고객이 말한 주소 그대로 남아야 다음 상담에서도 같은 주소로 이야기할 수 있습니다.
- **상세 주소**: 선택 입력입니다. 비우면 상세 주소 없이 표시합니다.
- **닫기**: 닫기(✕) · Esc · 딤 클릭으로 닫으면 입력란을 그대로 둡니다.

##### 진입 방식 1 · 입력 폼

[입력 폼](form-basic.html)의 주소 입력란이나 옆 ‘주소찾기’ 버튼으로 엽니다.

##### 진입 방식 2 · 인라인 편집

[인라인 편집](grid-inline.html) 테이블의 주소 셀에 ‘주소찾기’ 버튼을 둡니다.
셀의 주소 입력란을 눌러도 열립니다.
행마다 그 행의 주소 입력란에 표시합니다.

##### 진입 방식 3 · 사이드 패널

목록의 데이터 행에서 연 편집 [사이드 패널](option-panel.html) 안의 주소 입력란이나 ‘주소찾기’ 버튼으로 엽니다.
팝업은 사이드 패널 위로 뜨고, 고른 주소는 사이드 패널의 입력란에 표시됩니다.
목록에는 패널의 ‘저장’을 눌러야 반영됩니다.

유의사항주소찾기 팝업은 다른 팝업 위에 띄우지 않습니다.
팝업 위에 팝업이 쌓이면 지금 조작할 층과 닫히는 범위가 흐려지기 때문입니다. ([레이어 구조](layout-layer.html))

#### Do / Don't

###### Do · 이렇게 합니다

- 주소는 주소찾기 팝업에서 검색해 입력란에 표시합니다.
- 결과에서 도로명주소와 지번주소 중 고객이 말한 주소를 골라 표시합니다.
- 주소는 입력란 하나에 보여 줍니다.
- ‘주소찾기’ 버튼에 팝업 아이콘을 둡니다.
- 입력란을 눌러도 주소찾기 팝업이 열리게 합니다.

###### Don't · 이건 피합니다

- 주소를 직접 입력하게 두지 않습니다.
- 고른 지번주소를 도로명주소로 바꿔 표시하지 않습니다.
- 우편번호 · 기본 주소 · 상세 주소를 칸으로 나누지 않습니다.
- 주소찾기 팝업을 다른 팝업 위에 띄우지 않습니다.
