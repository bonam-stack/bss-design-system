### List

같은 구조의 항목을 반복해 늘어놓는 표현을 규정합니다.

#### 개요 · 언제 쓰나요?

List 는 같은 구조의 항목을 반복해 늘어놓는 표현입니다.
되풀이되는 한 건이 항목입니다 — 상담 이력 한 건, 첨부 파일 한 개.
무엇이 더 중요하고 무엇이 먼저인지가 늘어놓은 모양만으로 보여야 합니다.

List 는 항목을 **어떤 표현으로 늘어놓을지**를 규정합니다.
박스를 쌓아 **배치하는 방식**은 [Container](ui-comp-container.html) 의 스택이 규정합니다.

###### ✓ 이럴 때 사용합니다

- 같은 구조의 항목이 여럿이고, 차례로 훑어보게 하는 경우

###### ✕ 다른 패턴을 사용합니다

- 행과 열로 나눠 보거나 정렬 · 필터가 필요한 경우 → [테이블 모듈 공통 정의](grid-basic-behavior.html)
- 값을 입력받거나 고르게 하는 경우 → [Input](ui-comp-input.html) · [입력 폼 모듈 공통 정의](form-basic.html)
- 한 건만 담아 보이거나, 박스를 쌓아 배치하는 경우 → [Container](ui-comp-container.html)

#### 공통 기준

- **항목마다 구조를 같게 유지합니다**.
- **항목 사이를 구분선으로 가를 수 있습니다**.
- **치수는 디자인 가이드가 정합니다**.

#### List 유형

| 유형 | 사용자가 하는 것 |
| --- | --- |
| Data | 값을 읽습니다 |
| Activity | 지나온 일과 진행 상황을 확인합니다 |
| Navigation | 눌러서 넘어갑니다 |
| Bullet | 곁들인 안내를 읽습니다 |

##### Data

- **라벨은 왼쪽에, 값은 오른쪽 끝에 맞춥니다**: 값이 줄을 맞춰야 훑어 읽힙니다.
- **주소 · 상품명처럼 한 줄에 안 들어가는 값은 라벨을 위에 둡니다**: 오른쪽 끝 정렬은 값이 짧을 때 읽힙니다.
- **항목의 값이 비면 하이픈으로 표시합니다**: 빈칸은 값이 없는 것인지 아직 안 불러온 것인지 알 수 없습니다.

##### Activity

- **무슨 일이 있었는지를 제목에 적습니다**: 누가 했는지는 아래에, 활동 유형은 앞에 칩으로 둡니다.
- **이력은 최근 것을 위에, 진행 흐름은 차례대로 두고 선으로 잇습니다**: 선이 없으면 단계가 따로 일어난 일처럼 보입니다.
- **시각은 날짜와 시각으로 적습니다**: 이력은 나중에 정확한 시각을 다시 확인해야 합니다.

##### Navigation

- **누를 수 있다는 것을 보입니다**: 오른쪽 끝에 화살표를 둡니다.
- **항목 앞에 아이콘을 둘 수 있습니다**: 훑어 읽을 때 종류를 빨리 가립니다.
- **설명은 제목을 보조하는 한 줄로 둡니다**.
- **새로 생기거나 바뀐 항목을 표시합니다**.

##### Bullet

- **차례대로 따라야 하는 안내에는 번호를, 그렇지 않으면 점을 씁니다**: 번호가 있어야 몇 번째 단계인지 서로 가리킬 수 있습니다.

#### Do / Don't

###### Do · 이렇게 합니다

- 한 List 안에서 항목의 구조를 같게 유지합니다.
- 항목의 값이 비면 하이픈으로 표시합니다.
- 차례대로 따라야 하는 안내에는 번호를 매깁니다.

###### Don't · 이건 피합니다

- 행과 열로 나눠 다뤄야 하는 데이터를 List 로 늘어놓지 않습니다.
- 구조가 제각각인 항목을 한 List 로 늘어놓지 않습니다.
- 누를 수 있다는 것을 보이지 않은 채 넘어가게 하지 않습니다.
