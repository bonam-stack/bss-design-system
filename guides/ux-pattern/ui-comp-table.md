### Table

모든 테이블이 공통으로 갖추는 틀과, 값을 어떻게 표현하는지를 규정합니다.
헤더 · 셀 · 테이블 기능 순으로 정의합니다.

#### 개요 · 언제 쓰나요?

Table 은 여러 건의 데이터를 행과 열로 표시하는 UI 단위입니다.
표 하나만 가리키는 것이 아니라, 조건으로 좁히고 조작하고 결과를 확인하는 한 덩어리를 말합니다.

###### ✓ 이럴 때 사용합니다

- 여러 건을 나란히 놓고 견주어 봐야 할 때
- 항목마다 속성이 여럿이라 열로 나누어야 할 때
- 조회 결과를 정렬하거나 골라서 처리해야 할 때

###### ✕ 다른 패턴을 사용합니다

- 한 건만 자세히 보여 줄 때 → 상세 · 처리 패턴
- 건마다 담는 것이 달라 열을 맞출 수 없을 때 → 카드 형태
- 값을 선택하거나 입력하는 컴포넌트 → [Input](ui-comp-input.html)

조회 상태 · 행 hover와 클릭은 [테이블 모듈 공통 정의](grid-basic-behavior.html)가 규정합니다.
화면 유형별 구성은 각 패턴 문서가 규정합니다.

- 조회 · 목록 — [일반목록](grid-board.html) · [빅 테이블](grid-biggrid.html) · [트리형 목록](grid-tree.html) · [피벗 목록](grid-group.html) · [합계통계형 목록](grid-sum.html) · [멀티선택형 목록](grid-select.html) · [테이블 전체보기](grid-fullview.html)
- 입력 · 편집 — [인라인 편집 테이블](grid-inline.html) · [행확장 편집](grid-expand.html) · [순서 편집 테이블](grid-dnd-sort.html)

#### 공통 틀

테이블은 위에서 아래로 세 부분이 이어집니다.

- **액션 영역** — 목록을 조작하는 버튼이 놓입니다. 실행 · 내보내기 · 저장은 오른쪽에, 선택 묶음을 처리하는 액션과 누르는 즉시 범위를 좁히는 칩은 왼쪽에 둡니다.
- **표** — 행과 열로 값을 나열합니다. 헤더는 세로로 스크롤해도 위에 남습니다.
- **상태바** — 결과가 몇 건이고 어디까지 보고 있는지 알립니다.

#### 헤더

##### 정렬

열 제목을 눌러 정렬합니다.

- 누를 때마다 오름차순 · 내림차순이 번갈아 바뀝니다.
- 정렬할 수 있는 열은 마우스를 올렸을 때 흐린 방향 표시가 미리 나타납니다. 눌러 보기 전에도 정렬되는 열임을 알 수 있어야 합니다.
- 정렬된 열에 방향 표시를 남겨, 지금 무엇을 기준으로 보고 있는지 알립니다.
- 정렬은 **표 전체의 행**에 적용합니다. 열을 고정한 표에서 스크롤 영역의 열을 정렬해도 고정 열을 포함한 모든 행이 함께 다시 정렬됩니다.
- 편집 셀이 있는 열에는 정렬을 두지 않습니다. 정렬하면 어느 행을 고치던 중이었는지 흐트러집니다. 번호 · 일시 같은 읽기전용 열에만 둡니다.

##### 이중 헤더

여러 열이 한 묶음일 때 헤더를 두 줄로 쓸 수 있습니다.
윗줄에 묶는 이름을, 아랫줄에 열 이름을 적습니다.

- 묶이지 않는 열은 두 줄을 하나로 합쳐 씁니다.
- 묶음이 둘 이상이면 어디서 끊기는지 보이게 나눕니다.
- 가운데 맞춤은 묶는 이름에만 씁니다. 아랫줄 열은 값에 따라 맞춥니다.

##### 헤더 툴팁

열 제목만으로 뜻이나 기준이 전달되지 않을 때 사용합니다.

- 줄임말이나 업무 용어라서 제목만 보고는 무엇인지 알기 어려울 때
- 값을 어떻게 셌는지 알려야 할 때 (예. 해지는 빼고 센다 · 말일 기준)
- 툴팁이 있는 열은 제목 옆에 아이콘을 붙입니다. 아이콘이 없으면 설명이 있는지 모르고 지나칩니다.

#### 셀

##### 텍스트 정렬

- **숫자는 오른쪽**에 맞춥니다. (예. 금액 · 수량 · 비율) 자릿수가 나란해야 큰 값과 작은 값이 한눈에 보입니다.
- **글자와 날짜는 왼쪽**에 맞춥니다. (예. 상품명 · 담당자 · 주소 · 등록일) 시작점이 맞아야 위아래로 훑어 읽을 수 있습니다.
- **순번과 상태 칩은 가운데**에 맞춥니다.
- 열 제목도 그 열의 값과 같은 쪽으로 맞춥니다.

##### 줄바꿈

셀 안의 글자는 줄을 바꿀 수 있습니다.

- 열 폭에서 줄을 바꾸고, 행 높이가 그만큼 늘어납니다.
- 값이 길어도 온전히 보여 줘야 하는 열에 씁니다. (예. 안내 문구 · 비고)
- 열 폭을 좁게 써야 하면 말줄임으로 처리합니다. 줄인 값은 마우스를 올렸을 때 전체를 볼 수 있어야 합니다.

##### 셀 툴팁

열 폭이 모자라 한 줄로 줄여야 할 때, 마우스를 올리면 전체 값을 띄웁니다.

- 아이콘을 붙이지 않습니다. 말줄임표가 이미 값이 잘렸다는 것을 알려 줍니다.
- 꼭 읽어야 하는 값을 툴팁에만 두지 않습니다. 마우스를 올리지 않으면 보이지 않습니다.

##### 숫자 · 날짜 · 빈 값

- **숫자**: 크기를 견주는 값만 세 자리마다 쉼표로 끊습니다. (예. 금액 · 수량) 코드 · 사번 · 연도처럼 견주지 않는 값은 끊지 않습니다.
- **단위**: 열 제목에 적고 셀에는 숫자만 둡니다. (예. 열 제목 `금액(원)`)
- **자리가 정해진 번호**: 하이픈으로 끊습니다. (예. `010-0000-0000` · 사업자번호)
- **증감**: 부호와 색을 함께 씁니다. 늘어남은 성공 색, 줄어듦은 오류 색으로 표시합니다.
- **날짜**: 점으로 끊습니다. (예. `2026.09.01`) 시각까지 필요하면 뒤에 덧붙이고, 한 화면 안에서는 같은 형식을 씁니다.
- **빈 값**: 하이픈(`-`)으로 표시합니다. 빈칸으로 두면 값이 없는 것인지 아직 안 불러온 것인지 알 수 없습니다.

##### 상태값

- 상태값은 칩으로 감싸 다른 값과 구분합니다. 글자만 두면 다른 값에 묻힙니다.
- 상태마다 색을 다르게 하고, 같은 상태는 화면이 달라도 같은 색을 씁니다.
- 정해진 뜻이 없는 상태는 중립색을 씁니다.
- **상태값에도 링크를 걸 수 있습니다.** 링크를 걸어도 칩 형태는 유지합니다.

##### 보조 텍스트

주 값 뒤에 부가 정보를 덧붙일 수 있습니다.

- 열을 새로 만들 만큼은 아니지만 같이 보이면 이해가 빠른 값에 씁니다. (예. 상품명 뒤의 코드 · 지역)
- 주 값보다 작고 흐리게 두어 구분합니다.
- 못 보고 지나쳐도 일에 지장이 없는 값만 둡니다. 이것만 보고 판단해야 하는 값이라면 열로 만듭니다.

##### 여러 줄 편성

한 대상에 딸린 값들을 열로 나누지 않고 한 칸에 위아래로 쌓을 수 있습니다.

- 열이 많아 폭이 모자랄 때 씁니다.
- 맨 윗줄에 대표 값을 두고, 딸린 값은 그 아래에 작고 흐리게 둡니다.
- **여러 줄로 편성된 값도 각각 정렬할 수 있습니다.** 열 제목을 위아래로 나눠 값마다 정렬 기준을 둡니다.

##### 링크

글자에도 상태값에도 링크를 걸 수 있습니다.

- 링크는 **데이터 단위로** 정합니다. 같은 열이라도 이어 갈 화면이 있는 값에만 겁니다.
- 링크를 건 값은 다른 값과 구분되는 색으로 표시합니다.
- 무엇이 열리는지는 값 옆 아이콘으로 알립니다.

##### 편집 셀

값을 셀에서 직접 고치게 할 수 있습니다.

- 편집할 수 있는 셀은 옅은 배경의 상자로, 읽기전용 값은 상자 없는 텍스트로 표시합니다.
- 상자는 값을 넣는 방법에 따라 세 가지입니다. 값을 직접 치면 입력 상자, 정해진 값에서 고르면 드롭다운, 찾아서 넣으면 사이드 패널을 여는 버튼을 붙입니다.
- 편집 확정 · 셀 오류 · 행 추가는 [인라인 편집 테이블](grid-inline.html)이 규정합니다.

#### 테이블 기능

##### 상태바

표 아래에서 결과의 범위와 표시 방식을 제어합니다.
왼쪽부터 **총 건수 · 페이지네이션 · 개수 선택** 순으로 놓입니다.

**총 건수**

- 왼쪽에 `총 42건` 으로 표기합니다.
- **필터나 검색이 걸리면 그 결과에 맞춰 함께 바뀝니다.** 좁힌 결과와 전체를 함께 알릴 때는 `검색결과 n건 / 총 N건` 으로 적습니다.

**페이지네이션**

- **구성**: 번호를 가운데 두고, 양쪽에 한 페이지씩 옮기는 버튼(`‹` `›`)을, 그 바깥에 맨 처음·맨 마지막으로 가는 버튼(`«` `»`)을 둡니다.
- **번호는 열 개씩 끊어 보입니다**: 1~10 · 11~20처럼 열 개 단위로 보여 주고, 그 안에서 번호를 눌러 이동합니다. `›` 로 묶음의 끝을 넘어가면 다음 열 개로 바뀝니다.
- **한 페이지씩 이동하는 버튼은 숨기지 않습니다**: 첫 페이지에서 `‹`, 마지막 페이지에서 `›` 를 눌리지 않게 합니다.
- **맨 처음·맨 마지막 버튼은 묶음이 더 있을 때만 둡니다**: 앞 묶음이 있으면 `«`, 뒤 묶음이 있으면 `»` 를 둡니다. 묶음이 하나뿐이면 두지 않습니다. `«` 는 1페이지로, `»` 는 마지막 페이지로 갑니다. 묶음 하나를 건너뛰는 것이 아닙니다.

**개수 선택**

- 오른쪽에 한 번에 볼 행 수를 고르는 자리를 둡니다.
- 무한 스크롤을 쓰는 표에는 두지 않습니다. 대신 왼쪽에 `표시 40 / 총 240건` 으로 어디까지 불러왔는지 알립니다.

**어느 쪽을 쓰나요**

- **한 화면에 다 들어가면 둘 다 두지 않습니다.** 나눌 이유가 없을 때는 결과 수만 알립니다.
- 기본은 페이지네이션입니다. 페이지를 눌러 넘깁니다.
- 로그처럼 양이 많고 쭉 훑어보는 목록은 무한 스크롤을 씁니다. 아래로 내리면 이어서 불러옵니다.
- 합계나 그룹이 있는 표는 나누지 않습니다. 전부 한 화면에 있어야 서로 비교할 수 있습니다.
- 값을 고치는 표는 페이지네이션을 씁니다. 행이 계속 늘어나면 어느 행을 고치던 중인지 놓칩니다.

##### 선택 열

행을 골라 한꺼번에 처리해야 할 때 맨 왼쪽에 체크박스 열을 둡니다.

- 헤더 체크박스는 전부 고르면 체크, 일부만 고르면 줄표, 아무것도 안 골랐으면 빈칸입니다.
- 고른 행은 배경색으로 구분합니다.
- 고른 뒤의 처리는 [멀티선택형 목록](grid-select.html)이 규정합니다.

##### 행 추가

표에서 바로 새 항목을 넣게 할 수 있습니다.

- 표 아래에 전용 바를 두고, 누르면 맨 위에 빈 행이 하나 생깁니다.
- 번호와 등록일처럼 저장해야 정해지는 값은 빈 값으로 둡니다.
- 저장과 삭제는 [인라인 편집 테이블](grid-inline.html)이 규정합니다.

#### Do / Don't

###### Do · 이렇게 합니다

- 정렬된 열에 방향 표시를 남겨 지금 기준을 알립니다.
- 숫자는 오른쪽, 글자와 날짜는 왼쪽, 순번과 상태 칩은 가운데로 맞춥니다.
- 긴 글자는 줄을 바꾸거나, 한 줄로 줄이고 마우스를 올려 전체를 보게 합니다.
- 크기를 견주는 숫자만 세 자리마다 끊습니다.
- 링크는 이어 갈 화면이 있는 값에만 걸고, 무엇이 열리는지 아이콘으로 알립니다.
- 필터가 걸리면 총 건수도 함께 바꿉니다.

###### Don't · 이건 피합니다

- 편집 셀이 있는 열에 정렬을 두지 않습니다.
- 같은 열의 헤더와 셀 정렬을 다르게 두지 않습니다.
- 코드나 사번에 쉼표를 넣지 않습니다.
- 합계나 그룹이 있는 표를 페이지로 끊지 않습니다.
- 값을 고치는 표에 무한 스크롤을 쓰지 않습니다.
- 꼭 읽어야 하는 값을 툴팁이나 보조 텍스트에만 두지 않습니다.
