반복하는 동작을 키보드로 바로 실행하게 하는 단축키의 그룹과 배정, 제한하는 키를 규정합니다.
단축키는 PC에서 패키징된 NEXT BSS 창을 쓰는 환경을 전제로 합니다.

#### 개요 · 언제 쓰나요?

상담 · 업무 화면에서 자주 반복하는 동작을 마우스 대신 키보드로 실행하게 하는 체계입니다.
메뉴와 버튼을 찾는 시간을 줄여 반복 작업과 입력을 빠르게 처리하게 합니다.
단축키는 키 모양에 따라 다섯 그룹으로 나눕니다.
정보 유출이나 오조작으로 이어지는 키는 막습니다.

핵심 원칙단축키는 PC에서 패키징된 NEXT BSS 창을 쓰는 환경을 전제로 합니다.
패키징된 창에는 주소 표시줄 · 탭 같은 브라우저 요소가 없어, 그 안에서 누른 키를 브라우저보다 화면이 먼저 받습니다.
그래서 Ctrl+N · Ctrl+T · Ctrl+W 처럼 브라우저가 쓰는 키도 단축키로 씁니다.
NEXT BSS는 일반 브라우저 창에서도 쓸 수 있지만, 이때는 단축키 사용이 일부 제한될 수 있습니다.
브라우저가 먼저 쓰는 키는 화면까지 오지 않기 때문입니다. (예. Ctrl+N · Ctrl+T · Ctrl+W)

###### ✓ 이럴 때 사용합니다

- 같은 동작을 하루에도 여러 번 반복하는 경우 (예. 업무 탭 이동 · 고객정보 확인)
- 입력 중에 손을 마우스로 옮기지 않고 다음 동작으로 넘어가야 하는 경우

###### ✕ 다른 패턴을 사용합니다

- 가끔 쓰는 기능 → 버튼 · 메뉴로만 둡니다

#### 구성요소

1. 단축키 그룹키 모양이 같은 단축키를 한 그룹으로 묶습니다. 세션 탐색 · 기본 조작 · 세션 도구 · 사용자 지정 · 노드 조작 다섯 가지입니다.
2. 복사 · 붙여넣기 제한민감한 정보에서만 복사 · 붙여넣기 · 드래그를 막습니다. 그 밖의 화면에서는 그대로 씁니다.
3. 제한하는 키정보 유출이나 오조작으로 이어지는 키입니다. 눌러도 동작하지 않게 막습니다.
4. 피하는 키운영체제 · 브라우저 · 편집 · 표준 조작이 이미 쓰는 키입니다. 새 단축키를 정할 때 쓰지 않습니다.

#### 핵심 동작 · 상태

##### 단축키 그룹

단축키는 키 모양에 따라 다섯 그룹으로 나눕니다.
키 모양만 보고도 어떤 일을 하는 키인지 짐작할 수 있게 하기 위해서입니다.

| 그룹 | 키 모양 | 하는 일 | 동작하는 곳 |
| --- | --- | --- | --- |
| 세션 탐색 | Ctrl+숫자 · Ctrl+Tab · Ctrl+` | 업무세션 · 업무 탭 사이를 오갑니다 | 어느 화면에서나 |
| 기본 조작 | Ctrl+글자 · F1 | 업무세션 · 업무 탭을 열고 닫거나, 검색 · 초기화합니다 | 어느 화면에서나 |
| 세션 도구 | Ctrl+F1 부터 차례로 | 지금 업무세션(고객)에 딸린 화면 · 위젯 · 기능을 엽니다 | 어느 화면에서나 **(브라우저 환경 포함)** |
| 사용자 지정 | Alt+1~0 | 사용자가 고른 메뉴를 바로 엽니다 | 어느 화면에서나 **(브라우저 환경 포함)** |
| 노드 조작 | Ctrl+M · Ctrl+기호 · Ctrl+방향키 · Shift+1 · F2 · Enter · Space | 캔버스를 조작하고 노드 사이를 오갑니다 | 노드형 화면의 캔버스 영역 |

- **Shift를 더하면 반대 방향이나 더 큰 동작입니다**: Ctrl+Tab 다음 업무 탭 → Ctrl+Shift+Tab 이전 업무 탭.
- **브라우저 키는 같은 뜻일 때만 빌려 씁니다**: Ctrl+T 는 새 탭처럼 업무 탭을 더하고, Ctrl+W 는 탭 닫기처럼 업무 탭을 닫습니다.

##### 세션 탐색

업무세션과 업무 탭 사이를 오가는 키입니다.

| 기능 | 키 |
| --- | --- |
| 주 업무세션 이동 | Ctrl+1 · Ctrl+2 · Ctrl+3 … |
| 지원업무세션 이동 | Ctrl+` |
| 다음 업무 탭 이동 | Ctrl+Tab |
| 이전 업무 탭 이동 | Ctrl+Shift+Tab |

- **주 업무세션은 GNB의 순서대로 번호를 붙입니다**: Ctrl+1 이 첫 번째 주 업무세션입니다.
- **지원업무세션은 숫자 1 왼쪽 키를 씁니다**: 주 업무세션 번호 줄과 같은 줄에 두어 함께 익히게 합니다.

##### 기본 조작

업무세션 · 업무 탭을 열고 닫거나, 화면 전체에 걸리는 동작을 하는 키입니다.

| 기능 | 키 |
| --- | --- |
| 새 업무세션 추가 | Ctrl+N |
| 업무 탭 추가 | Ctrl+T |
| 현재 업무 탭 닫기 | Ctrl+W |
| 업무세션 닫기 | Ctrl+Q |
| 전체메뉴 검색 | Ctrl+F |
| 전체 초기화 | Ctrl+Shift+R |
| 도움말 | F1 |

- **업무세션 닫기는 다이얼로그로 확인합니다**: 업무세션 안의 업무 탭이 모두 닫히기 때문입니다. 닫히는 것은 그 업무세션뿐이며, 로그인과 다른 업무세션은 그대로 유지됩니다.
- **전체 초기화는 다이얼로그로 확인합니다**: 열린 화면과 업무세션을 모두 닫고 NEXT BSS를 다시 불러옵니다.

##### 세션 도구

지금 보고 있는 업무세션(고객)에 딸린 화면 · 위젯 · 기능을 바로 여는 키입니다.

| 기능 | 키 |
| --- | --- |
| 워크스페이스 | Ctrl+F1 |
| 고객정보 위젯 펼치기 · 접기 | Ctrl+F2 |
| 고객 인증하기 | Ctrl+F3 |

- **워크스페이스는 고객마다 따로 있습니다**: Ctrl+F1 은 지금 업무세션의 고객 워크스페이스로 이동합니다.
- **고객정보 위젯은 같은 키로 펼치고 접습니다**: 고객정보를 보면서 응대하는 일이 많아 어느 화면에서나 같은 키로 엽니다.
- **세션 도구는 더할 수 있습니다**: 업무세션(고객)에 딸린 기능을 새로 둘 때는 Ctrl+F4 부터 차례로 이어 붙입니다. 제한하는 키와 피하는 키에 드는 키는 건너뜁니다.

##### 사용자 지정

사용자가 자주 쓰는 메뉴에 단축키를 붙이는 메뉴 바로가기입니다.

- **메뉴 바로가기**: 메뉴를 골라 Alt+1~0 중 하나를 붙입니다. 최대 10개까지 등록합니다.
- **등록 순서**: 메뉴를 검색하거나 메뉴 트리에서 고른 뒤, 키를 골라 저장합니다.
- **자동 실행**: 바로가기마다 켜고 끕니다. 켜면 화면을 열면서 그 메뉴의 기본 동작(조회 · 검증)까지 실행합니다.
- **이미 쓰는 키**: 다른 메뉴에 붙인 키를 고르면 등록하지 않고 이유를 알립니다.
- **되돌리기**: 처음 배정으로 되돌리는 기능을 둡니다.

##### 노드 조작

노드형 화면의 캔버스 영역에 포커스가 있을 때만 동작하는 키입니다.

| 기능 | 키 |
| --- | --- |
| 모드 전환 (전체보기 ↔ 진행) | Ctrl+M |
| 확대 · 축소 | Ctrl++ · Ctrl+- |
| 맞춤 (기본 배율로 현재 노드 보기) | Shift+1 |
| 화면 이동 (손 도구) | Space 를 누른 채 드래그 |
| 다음 · 이전 노드 | Ctrl+→ · Ctrl+← |
| 완료한 노드 다시 편집 | Ctrl+← 로 노드를 옮긴 뒤 F2 |
| 노드 하단 CTA 실행 | Enter |

- **HUD와 같은 동작입니다**: 모드 토글 · 줌 컨트롤(확대 · 축소 · 맞춤 · 손 도구)을 키로 실행합니다.
- **입력칸 안에서는 표준 동작이 먼저입니다**: 입력칸 안의 Ctrl+방향키는 단어 단위 이동으로, Shift+1 은 ‘!’ 입력으로 동작합니다. 노드 이동과 맞춤은 입력칸 밖에 포커스가 있을 때 동작합니다.
- **손 도구는 버튼에 포커스가 없을 때만 동작합니다**: 버튼에 포커스가 있으면 Space 는 버튼을 누르는 표준 동작입니다.
- **다시 편집은 그 노드의 ‘수정’ 버튼과 조건이 같습니다**: 고칠 수 없는 노드에서 F2 를 누르면 이유를 토스트로 알립니다. 편집을 취소할 때는 Esc 를 누릅니다.
- **Enter는 노드 하단 CTA를 실행합니다**: 폼에서 Enter로 제출하는 표준 동작과 같습니다. 다른 버튼에 포커스가 있으면 그 버튼을 누르고, Text Area 안에서는 줄을 바꿉니다.
- **되돌리기 어려운 CTA는 다이얼로그로 확인합니다**: Enter 를 눌러도 바로 실행하지 않습니다.

##### 복사 · 붙여넣기는 민감한 정보에서만 막습니다

Ctrl+C · Ctrl+V · 드래그 복사는 상담 업무에서 자주 쓰는 기본 조작입니다.
그래서 화면 전체에서 막지 않고, 민감한 정보에서만 막습니다.

- **막는 곳**: 마스킹을 해제한 개인정보처럼 민감한 정보입니다. 그 값에서는 복사 · 붙여넣기 · 드래그를 할 수 없습니다.
- **그대로 쓰는 곳**: 그 밖의 값과 입력칸에서는 복사 · 붙여넣기를 할 수 있습니다.
- **막는 범위는 마스킹 처리와 같습니다**: 어떤 정보가 민감한 정보인지는 [마스킹 처리](resp-masking.html)를 따릅니다.

##### 제한하는 키

아래 키는 단축키로 쓰지 않고, 눌러도 동작하지 않게 막습니다.

| 키 | 막는 이유 |
| --- | --- |
| PrintScreen · 캡처 단축키 | 화면 캡처를 통한 정보 유출 방지 |
| Ctrl+P | 무단 출력 방지 |
| F12 · Ctrl+Shift+I | 개발자 도구로 화면 · 요청을 바꾸려는 시도 차단 |
| F5 · Ctrl+R · Backspace | 작성 중인 데이터 손실 · 중복 전송 같은 오조작 방지 |

- **Backspace는 입력칸 밖에서만 막습니다**: 입력칸 안에서는 글자를 지우는 표준 동작 그대로 둡니다. 입력칸 밖에서 눌러 이전 화면으로 돌아가는 동작만 막습니다.

##### 새 단축키를 정할 때 피하는 키

다섯 그룹에 없는 기능에 단축키를 더할 때는 이미 배정한 키, 제한하는 키와 함께 아래 키를 피합니다.

| 구분 | 키 | 이유 |
| --- | --- | --- |
| 운영체제 | Alt+Tab · Alt+F4 · Ctrl+Alt+Del · Ctrl+Shift+Esc · Win 키 조합 | 창 전환 · 창 닫기 · 보안 화면 · 작업 관리자 |
| 브라우저 | Ctrl+L · Ctrl+H · Ctrl+J · Ctrl+S · Alt+F · Alt+E · Alt+D · Alt+← · Alt+→ · F3 · F7 · F10 · F11 | 브라우저의 다른 동작으로 익숙한 키입니다 |
| 편집 | Ctrl+C · Ctrl+V · Ctrl+X · Ctrl+Z · Ctrl+Y · Ctrl+A · Ctrl+B · Ctrl+I · Ctrl+U | 복사 · 붙여넣기 · 실행 취소 · 전체 선택 · 서식 |
| 표준 조작 | Esc · Enter · Tab · 방향키 · Space | 닫기 · 실행 · 포커스 이동 · 선택 |
| 사용자 지정 | Alt+1~0 | 메뉴 바로가기 자리로 비워 둡니다 |

- 상담 PC 에 함께 실행되는 프로그램이 쓰는 키도 피합니다.

##### 기본 기능을 따르되 제어하는 키

Tab · Enter · Esc · Space · 방향키는 운영체제와 브라우저의 기본 기능을 따릅니다.
아래 표의 경우만 따로 제어합니다.

| 키 | 제어하는 경우 | 제어한 동작 | 이유 |
| --- | --- | --- | --- |
| Tab | GNB | Tab 한 번으로 들어가고 나오며, 안에서는 방향키로 업무세션 사이를 옮겨 갑니다 | 모든 화면에 반복되는 GNB를 매번 지나지 않고 본문에 닿게 합니다 |
| Tab | 업무 화면이 열릴 때 | 조회조건의 첫 필드에서 시작합니다 | 화면을 연 뒤 바로 조회조건을 입력하게 합니다 |
| Tab | 팝업 · 사이드 패널이 열려 있을 때 | 포커스가 그 안에서만 옮겨 갑니다 | 레이어가 열린 동안 뒤 화면은 조작하지 않습니다 |
| Esc | 팝업 · 사이드 패널 · 페이지 전환 등 모든 레이어 | 맨 위의 레이어 하나를 닫고, 포커스를 그 레이어를 연 요소로 돌려보냅니다 | 모든 레이어를 같은 키로 닫아 닫는 방법을 예측할 수 있게 합니다 |
| Enter · Space | 노드형 화면의 캔버스 | 노드 하단 CTA를 실행하고, 손 도구로 화면을 옮깁니다 | 노드 조작 절을 따릅니다 |

- **Tab의 포커스 순서는 보이는 화면을 기준으로 합니다**: GNB를 제외하고, Tab으로 포커스를 받는 링크 · 버튼 등은 왼쪽에서 오른쪽, 위에서 아래 순서로 포커스를 받습니다. 이 순서가 기본 기능 그대로 나오도록 마크업 순서를 화면 순서와 맞춥니다.
- **선택 · 실행 요소는 표준 요소로 만듭니다**: 기본 기능 그대로 Tab으로 포커스를 받고 Enter · Space로 실행됩니다.
- **폼의 CTA는 기본적으로 제출 버튼으로 둡니다**: 필드에서 Enter를 누르면 CTA가 실행됩니다. (예. 조회조건의 ‘조회’) 업무에 따라 일반 버튼으로 둘 수 있습니다.
- **어느 레이어가 맨 위인지는 레이어 구조를 따릅니다**: 겹친 레이어의 순서는 [레이어 구조](layout-layer.html)의 밴드로 정합니다.

#### Do / Don't

###### Do · 이렇게 합니다

- 새 단축키는 다섯 그룹 중 키 모양이 맞는 그룹에 넣습니다.
- 어느 화면에서나 동작하는 단축키는 조합 키로 정합니다.
- 같은 기능은 어느 화면에서나 같은 키로 실행합니다.
- 복사 · 붙여넣기는 민감한 정보에서만 막습니다.
- 팝업 · 사이드 패널 · 페이지 전환 등 모든 레이어를 Esc로 닫게 합니다.

###### Don't · 이건 피합니다

- 제한하는 키를 단축키로 쓰지 않습니다.
- 브라우저 키를 브라우저와 다른 뜻으로 빌려 쓰지 않습니다.
- 같은 키에 화면마다 다른 기능을 배정하지 않습니다.
- 표에 정한 경우 밖에서 Tab · Enter · Esc · Space 의 기본 기능을 바꾸지 않습니다.
- 되돌리기 어려운 동작을 단축키 하나로 바로 실행하지 않습니다.
- 단축키로만 실행할 수 있는 기능을 두지 않습니다.

#### 부록 · 스윙 단축키와 비교

이전 시스템(스윙)의 단축키와 이 문서의 단축키를 기능별로 맞대어 봅니다.
NEXT BSS의 단축키는 스윙의 단축키 체계를 최대한 이어받았습니다.
바뀐 키는 UI 콘셉트가 바뀌면서 부득이하게 조정한 것입니다.
스윙에 익숙한 사용자에게 바뀐 키를 안내할 때 참고합니다.

- **메뉴 보기 · 숨기기는 전체메뉴 검색으로 합쳤습니다**: NEXT BSS에서는 전체메뉴 검색(Ctrl+F)이 메뉴를 찾아 여는 역할을 맡습니다. 그래서 메뉴를 보이고 숨기는 키는 따로 두지 않습니다.
- **Ctrl+F1 · Ctrl+F2 · Ctrl+F3 은 세션 도구로 다시 배정했습니다**: 스윙에서 쓰던 이 세 키를, 지금 활성화된 주 업무세션(고객)의 기능을 여는 키로 옮겼습니다. 워크스페이스(Ctrl+F1) · 고객정보 위젯 펼치기 · 접기(Ctrl+F2) · 고객 인증하기(Ctrl+F3)입니다.
- **현재 화면의 초기화는 제한하는 정책으로 바꾸었습니다**: 화면 하나를 초기화하면 그 화면에 입력한 데이터가 사라집니다. 잘못 눌러 데이터를 잃는 일을 막으려고 NEXT BSS에서는 이 기능을 제한합니다. 화면을 처음 상태로 돌려야 하면 확인 다이얼로그를 거치는 전체 초기화(Ctrl+Shift+R)를 씁니다.
- **스윙에 없던 키**: 새 업무세션 추가(Ctrl+N) · 업무 탭 추가(Ctrl+T) · 업무세션 닫기(Ctrl+Q) · 지원업무세션 이동(Ctrl+`) · 노드 조작 키입니다.
