노드를 진행하다 막혔을 때 무엇을 보여 주고 그다음 무엇을 하게 할지 규정합니다.
노드 프로세스를 진행하다 발생한 오류는 모두 완결형 노드 모듈로 처리합니다.

#### 개요 · 언제 쓰나요?

막힌 범위로 먼저 갈립니다.

| 어디가 막혔습니까 | 무엇이 규정합니까 |
| --- | --- |
| 화면 전체를 열 수 없습니다 | [전역 예외 화면](resp-error-page.html) |
| 화면은 살아 있고 노드가 막혔습니다 | 이 문서 |

전역 안내와 시스템 상태를 알리는 Global Message도 [전역 예외 화면](resp-error-page.html)이 규정합니다.
컨텐트 모듈에 속하지 않고 화면 전체를 범주로 하기 때문입니다.

**노드 프로세스를 진행하다 발생한 오류는 모두 완결형 노드 모듈로 처리합니다.** 막힌 자리에서 원인을 알리고 다음 조치를 함께 제공합니다.

| 어떤 상황 | 노드가 보여 주는 것 |
| --- | --- |
| 노드 업무에 접근할 권한이 없습니다 | 불가 결과와 권한 요청 · 이관 |
| 조회·처리가 실패했습니다 | 오류 코드와 사유, 다시 시도 |
| 업무 프로세스에 이슈가 생겼습니다 | 보류·불가 결과와 사유, 다음 조치 |

###### ✓ 이럴 때 사용합니다

- 권한이 없어 편성된 노드를 진행할 수 없는 업무
- 조회·처리가 실패해 다시 시도해야 하는 업무
- 업무 프로세스 이슈로 더 진행할 수 없는 업무

###### ✕ 다른 패턴을 사용합니다

- 막힌 경로를 대체 경로로 이어야 할 때 → [분기 진행](node-flow-branch.html)
- 입력값이 규칙에 맞지 않을 때 → [폼 유효성 체크](resp-form-validation.html)

#### 권한으로 중단될 때

| 구분 | 내용 |
| --- | --- |
| 노드 | 원래 내용을 감추고 완결형 모듈로 바꿉니다 |
| 다음 조치 | [권한 요청]과 [이관]을 두고, [상담 종료]로 마칩니다 |
| 이후 처리 | 승인 뒤 다시 진입하면 화면이 갱신되며 막힌 노드부터 이어서 진행합니다 |

권한이 없는 노드도 업무에 편성될 수 있습니다.
**업무를 시작하면 앞 노드를 진행하지 않고 곧바로 권한이 없는 노드로 이동합니다**: 그 노드를 처리할 수 없으면 업무를 끝낼 수 없으므로, 앞 단계를 밟게 하지 않습니다.
[이관]은 특정 채널만 쓰는 기능이므로 옵션입니다.

갱신은 [스킵](node-flow-skip.html)이 규정합니다.

#### 시스템 이슈로 중단될 때

| 구분 | 내용 |
| --- | --- |
| 노드 | 오류 코드와 사유를 표시합니다 |
| 다음 조치 | [오류 정보 조회]와 [담당자에게 문의]를 두고, [다시 시도]로 재시도합니다 |
| 이후 처리 | 해결되면 이어서 진행하고, 해결되지 않으면 중단된 노드에서 마무리합니다 |

**처리를 시도한 뒤에 결과를 보여 줍니다**: 진입하는 순간 실패를 띄우지 않고, 시도하는 동안을 노드 헤더에 표시합니다.

#### 프로세스 이슈로 중단될 때

업무 프로세스에 이슈가 생겨 더 진행할 수 없는 경우입니다.
노드에 보이는 형태는 시스템 이슈와 같고 원인만 다릅니다.

| 구분 | 내용 |
| --- | --- |
| 노드 | 결과 배너로 보류인지 불가인지 알리고 사유를 적습니다 |
| 다음 조치 | 상황에 맞는 조치와 [상담 종료]를 둡니다 |
| 이후 처리 | 사용자가 고른 조치를 따릅니다 |

**더 진행할 수 없으면 다음 노드가 그 결과 노드로 바뀝니다**: 원래 편성돼 있던 뒤 노드는 그때 사라집니다.

세 경우 모두 결과 배너와 다음 조치는 [완결형 모듈](node-comp-end.html)이 규정합니다.

#### Do / Don't

###### Do · 이렇게 합니다

- 노드 프로세스를 진행하다 발생한 오류는 완결형 노드 모듈로 처리합니다.
- 막힌 자리에는 다음에 무엇을 할지 함께 둡니다.
- 권한이 없는 노드가 편성돼 있으면 업무를 시작할 때 그 노드로 이동합니다.
- 권한이 승인되면 막힌 노드부터 이어서 진행합니다.

###### Don't · 이건 피합니다

- 노드 프로세스에서 발생한 오류를 Global Message로 올리지 않습니다.
- 노드 하나가 막혔다고 화면을 덮지 않습니다.
- 원인만 알리고 다음 행동을 주지 않습니다.
- 진행 불가 상태의 노드를 그대로 통과시키지 않습니다.
